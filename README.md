# 88 studio waitlist

Responsive waitlist landing page for 88 studio, with locally hosted fonts and images, a rotating 3D mark, and an animated mint dot background.

## Preview

Serve this directory with any static HTTP server, for example:

```sh
npx --yes serve .
```

## Files

- `index.html`: page markup and responsive styles
- `app.js`: animation and email form behavior
- `assets/`: images, SVG, and font files

The email form validates email addresses and saves them in the visitor's browser local storage. It does not send addresses to a shared database or email service.

Visual reference: https://enrolment.framer.ai/
